# Experiment Explorer

A React + TypeScript project using Vite. The app currently renders a minimal starter screen confirming that the setup is running. No experiment functionality has been added.

## Getting started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Commands

- `npm run dev`: start the development server.
- `npm run build`: type-check the project and create a production build in `dist`.
- `npm run lint`: run the linter.
- `npm run preview`: preview the production build locally after building it.

## Structure

- `src/App.tsx`: application starter screen.
- `src/main.tsx`: React entry point.
- `src/index.css`: base stylesheet.
- `vite.config.ts`: Vite configuration.

Dependencies and configuration follow the official [Vite React TypeScript starter](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts).
